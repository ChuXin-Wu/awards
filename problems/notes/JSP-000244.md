# JSP-000244: exact finite verification and a good-prime certificate

[Problem record](../catalog-0201-0300.md#JSP-000244) · [Search program](../../scripts/search_unit_fraction_gaps.py) · [Certificate verifier](../../scripts/verify_unit_fraction_good_prime_chain.py)

This note proves that every fixed denominator count reduces to a finite exact
search, records the repository's verification through 100 denominators, and
checks a finite good-prime certificate. The combined result is that any
counterexample must satisfy

\[
n_1>39943925344138028689
\quad\text{and}\quad
k\geq68634921076157089631.
\]

This is a much stronger finite exclusion, but it does **not** prove the
unrestricted conjecture.

## Statement

The conjecture asks whether every representation

\[
1=\frac1{n_1}+\cdots+\frac1{n_k},\qquad 1<n_1<\cdots<n_k,
\]

has some consecutive gap at least 3.

## Finite-reduction lemma

Fix an integer \(k\geq2\). If a counterexample of length \(k\) exists, it is
among the finitely many sequences obtained by choosing

\[
n_1\in\{2,\ldots,k-1\}
\quad\text{and}\quad
(n_{i+1}-n_i)_{i=1}^{k-1}\in\{1,2\}^{k-1}.
\]

**Proof.** In a counterexample every gap is a positive integer smaller than 3,
so every gap is 1 or 2. It remains to bound the first denominator. If
\(n_1\geq k\), then \(1/n_i\leq1/n_1\) for every \(i\), with a strict
inequality for every \(i>1\). Therefore

\[
\sum_{i=1}^k\frac1{n_i}<\frac{k}{n_1}\leq1,
\]

contradicting the required equality. Hence \(2\leq n_1<k\), and the stated
finite enumeration is exhaustive. \(\square\)

## Sound pruning lemma

Suppose a partial candidate currently ends at denominator \(c\), has reciprocal
sum \(S\), and still needs \(r\) denominators. For the \(j\)th future
denominator \(m_j\), the gap restriction gives

\[
c+j\leq m_j\leq c+2j.
\]

Consequently every completion has its remaining sum in the exact interval

\[
\sum_{j=1}^r\frac1{c+2j}
\ \leq\
\sum_{j=1}^r\frac1{m_j}
\ \leq\
\sum_{j=1}^r\frac1{c+j}.
\]

It is therefore sound to discard a branch when the upper endpoint added to
\(S\) is below 1, or when the lower endpoint added to \(S\) is above 1. Equality
is not pruned. These are exactly the two pruning rules used by the program.

## Prime-power obstruction

Let \(m_1,\ldots,m_s\) be positive integers whose reciprocal sum is an
integer. For every prime \(p\), the maximum of

\[
v_p(m_1),\ldots,v_p(m_s)
\]

cannot be positive and attained exactly once.

**Proof.** Let \(L=\operatorname{lcm}(m_1,\ldots,m_s)\), and suppose the
positive maximum \(e\) is attained only at \(m_j\). After multiplying the
reciprocal sum by \(L\), every term \(L/m_i\) with \(i\ne j\) is divisible by
\(p\), while \(L/m_j\) is not. Their sum is therefore nonzero modulo \(p\).
The other side is an integer multiple of \(L\), hence is zero modulo \(p\), a
contradiction. \(\square\)

This gives a third sound pruning rule. If a partial branch has a unique
largest \(p\)-power and no future denominator in the full reachable interval
can be divisible by that power, every completion retains a unique maximum and
cannot sum to 1. A future denominator with a still higher \(p\)-valuation is
also a multiple of the current power, so the test does not discard that
possibility.

The unique-maximum obstruction alone cannot settle the conjecture. For an
explicit certificate, let

\[
S=[7,62]\setminus\{32,37,41,43,47,49,53,59,61\}.
\]

The omitted integers are never consecutive, so the ordered elements of \(S\)
have gaps at most 2. Nevertheless no prime has a positive maximal valuation
attained exactly once on \(S\). For \(p=2,3,5\), the respective top layers are
\(\{16,48\}\), \(\{27,54\}\), and \(\{25,50\}\). The sole multiple \(49\)
of \(7^2\) is omitted, leaving several multiples of 7 in the top layer. Every
prime from 11 through 31 has at least two selected multiples, while every
prime from 37 through 61 is itself omitted and has no selected multiple.
Primes above 61 divide no element of \(S\). Thus any proof must use more than
the multiplicity of the top layer; the residue carried by that layer matters.

## Full p-adic congruence

The search now uses the following stronger form of the same obstruction. Let
\(e=\max_i v_p(m_i)>0\), and write every denominator in the top layer as
\(m_i=p^e t_i\), where \(p\nmid t_i\). If the reciprocal sum is an integer,
then

\[
\sum_{v_p(m_i)=e}t_i^{-1}\equiv0\pmod p.
\tag{TL}
\]

Indeed, put \(L=\operatorname{lcm}(m_1,\ldots,m_s)\) and \(C=L/p^e\).
After multiplying the reciprocal sum by \(L\) and reducing modulo \(p\), all
terms below the top layer vanish, while a top-layer term becomes
\(C/t_i\equiv C t_i^{-1}\pmod p\). Since \(p\nmid C\), cancellation of \(C\)
gives (TL).

The implementation retains more than this first congruence digit. For every
denominator divisible by \(p\), write
\(m_i=p^{e_i}t_i\) with \(p\nmid t_i\), where
\(e=\max_i e_i\). The same calculation before reduction modulo \(p\) gives

\[
\sum_{e_i>0}p^{e-e_i}t_i^{-1}\equiv0\pmod {p^e}.
\tag{PA}
\]

Equation (TL) is the reduction of (PA) modulo \(p\). Keeping (PA) also retains
the carries from lower \(p\)-adic layers.

For a partial branch, suppose no integer in the full reachable future interval
is divisible by \(p^{e+1}\). The current top layer will then remain the top
layer. The program computes every residue obtainable by choosing an arbitrary
subset of all reachable future multiples of \(p\), normalized as in (PA). It
deliberately ignores the gap condition and the number of remaining positions,
so this is an over-approximation of all genuine completions. If even this
larger residue set cannot cancel the current residue in (PA), pruning the
branch is sound. If a higher layer is reachable, or if a deliberately imposed
residue-set size cap is exceeded, the program keeps the branch.

The earlier unique-maximum rule is the special case in which the current top
layer has one term and there is no reachable term in the same or a higher
layer. Retaining the complete congruence is substantially stronger. For
example, the two top-layer multiples \(31\) and \(62\) do not have a unique
maximum 31-adic valuation, but their cofactor-reciprocal sum is
\(1+1/2\not\equiv0\pmod {31}\).

## An exact forbidden-pair reduction

The congruence gives a precise sufficient condition that would finish the
unbounded problem if it could be established at every scale. Fix a prospective
largest denominator \(M\). Call \(n\leq M\) *\(M\)-forbidden* if there are a
prime \(p\) and an exponent \(E\geq1\) such that, on writing

\[
p^E\parallel n,\qquad p^{E+1}>M,\qquad
s=\left\lfloor\frac{M}{p^E}\right\rfloor,\qquad
r=\frac{n}{p^E},
\]

no subset \(T\subseteq\{1,\ldots,s\}\) containing \(r\) satisfies

\[
\sum_{t\in T}t^{-1}\equiv0\pmod p.
\tag{F}
\]

Every denominator occurring in an integer reciprocal sum whose largest
denominator is at most \(M\) is not \(M\)-forbidden. Indeed, if an
\(M\)-forbidden \(n\) were selected, then \(p^{E+1}>M\) would make \(E\) the
largest selected \(p\)-adic valuation. The selected top-layer denominators
would be \(p^Et\) for a subset \(T\subseteq\{1,\ldots,s\}\) containing \(r\).
The top-layer congruence (TL) would give (F), contrary to the definition.
Notice that \(s<p\), so all the displayed inverses exist modulo \(p\).

There is also an endpoint bound independent of the gap condition. If a
counterexample starts at \(a\) and ends at \(M\), then

\[
1\leq\sum_{n=a}^{M}\frac1n
<\int_{a-1}^{M}\frac{dx}{x}
=\log\frac{M}{a-1}.
\]

Consequently \(M>e(a-1)\), and hence

\[
a\leq\left\lceil\frac{M}{e}\right\rceil.
\tag{EP}
\]

It follows that the original conjecture would be proved if one could show that
for every sufficiently large \(M\), the interval

\[
\left[\left\lceil\frac{M}{e}\right\rceil,M\right]
\]

contains two consecutive \(M\)-forbidden integers. Both integers cannot be
selected, while the gap condition says that every two consecutive integers
between the selected endpoints \(a\) and \(M\) contain a selected denominator.
The finitely many smaller values of \(M\) could then be checked exactly.

This is an unconditional reduction, not an assertion that the required pair
always exists. Every nonexceptional link in the good-prime obstruction below
constructs such a pair: the large prime \(p\) is forbidden, and one of
\(p-1,p+1\) is \(2q\), whose multiplier \(2\) belongs to no zero-sum subset of
the available multipliers modulo \(q\). The initial \(q=11\) case is a small
exception to the global definition above; the good-prime proof handles it
using the independently established lower endpoint \(a\geq13\).

### An elementary logarithmic-cofactor criterion

The subset condition (F) has a useful closed-form sufficient test. Put

\[
L_s=\operatorname{lcm}(1,\ldots,s),
\qquad
A_s=L_s\sum_{t=1}^{s}\frac1t.
\]

Both quantities are integers. If \(p\) is prime, \(s<p\), and \(p>A_s\),
then no nonempty subset \(T\subseteq\{1,ldots,s\}\) has

\[
\sum_{t\in T}t^{-1}\equiv0\pmod p.
\tag{LC}
\]

Indeed, after multiplication by \(L_s\), the sum in (LC) has an integer
numerator between 1 and \(A_s<p\); also \(p\nmid L_s\). It therefore cannot
vanish modulo \(p\).

Consequently, if \(s=\lfloor M/p\rfloor<p\) and \(p>A_s\), every multiple
\(pr\leq M\) is \(M\)-forbidden. Indeed, \(r\leq s<p\), while
\(M<p(s+1)\leq p^2\); hence \(p\parallel pr\), and one may use \(E=1\) in
(F). The required subset would be nonempty because it contains \(r\). This
includes, but is not limited to, the fixed small-multiplier tests used in the
good-prime argument.

The prime number theorem in the equivalent form
\(\log L_s=\psi(s)=s+o(s)\), together with
\(H_s=\log s+O(1)\), gives

\[
\log A_s=s+o(s).
\]

Thus, for every fixed \(\eta>0\) and all sufficiently large \(p\), the simple
condition

\[
\left\lfloor\frac Mp\right\rfloor\leq(1-\eta)\log p
\tag{LCF}
\]

makes every multiple of \(p\) up to \(M\) forbidden. In particular, a full
proof would follow if every sufficiently large interval
\([\lceil M/e\rceil,M]\) contained consecutive integers each possessing a
prime divisor satisfying (LCF). Establishing such adjacent almost-primes in
every multiplicative interval is itself beyond the presently used prime
distribution input; (LCF) is a rigorous sufficient condition, not an assertion
that such a pair always exists.

### Forbidden integers need an almost-linear prime-power divisor

The preceding reduction has a strong asymptotic restriction. For every
\(\theta>0\), there is an \(M_0(\theta)\) such that, whenever
\(M\geq M_0(\theta)\), every \(M\)-forbidden integer has a prime-power divisor

\[
Q>M^{1-\theta}.
\tag{AL}
\]

To prove this, use Theorem 5 of Conlon, Fox, He, Mubayi, Pham, Suk, and
Verstraëte,
[A question of Erdős and Graham on Egyptian fractions](https://homepages.math.uic.edu/~mubayi/papers/Egypt.pdf).
That theorem says the following. Given fixed \(\delta,\varepsilon>0\), for
every sufficiently large prime power \(q\), if

\[
I\subseteq[q^\varepsilon,2q^\varepsilon],\qquad
\gcd(x,q)=1\quad(x\in I),\qquad |I|\geq\delta q^\varepsilon,
\]

then every residue modulo \(q\) is a sum of inverses of a subset of \(I\).

Fix \(0<\varepsilon<1\), and suppose \(n\) is \(M\)-forbidden, witnessed by
\(p,E\), with \(Q=p^E\), \(s=\lfloor M/Q\rfloor\), and \(r=n/Q\) as above.
If \(p\) is sufficiently large and \(s\geq2p^\varepsilon\), let

\[
I=\bigl([p^\varepsilon,2p^\varepsilon]\cap\mathbb Z\bigr)\setminus\{r\}.
\]

For all sufficiently large \(p\), every element of \(I\) is smaller than
\(p\), and \(|I|\geq p^\varepsilon/2\). The quoted theorem, with
\(q=p\) and \(\delta=1/2\), supplies a subset \(B\subseteq I\) such that

\[
\sum_{t\in B}t^{-1}\equiv-r^{-1}\pmod p.
\]

Moreover \(I\subseteq\{1,\ldots,s\}\) and \(r\notin I\), so
\(B\cup\{r\}\) contradicts the defining condition (F). Hence, for all large
witness primes,

\[
s<2p^\varepsilon,
\qquad
\frac{M}{Q}<s+1<3p^\varepsilon,
\]

Since \(p\leq Q\), it follows that

\[
Q>\left(\frac M3\right)^{1/(1+\varepsilon)}.
\tag{4}
\]

There are only finitely many remaining witness primes, say \(p\leq P_0\).
For those, \(pQ=p^{E+1}>M\), so \(Q>M/P_0\). Given \(\theta>0\), choose
\(\varepsilon\) so that \(1/(1+\varepsilon)>1-\theta\). For sufficiently
large \(M\), both (4) and \(Q>M/P_0\) imply (AL), proving the claim.

The qualitative exponent \(1-o(1)\) can be made explicit. There is an
absolute constant \(C>0\) such that every sufficiently large
\(M\)-forbidden integer has a prime-power divisor \(Q\) satisfying

\[
Q>
M\exp\!\left(
-C(\log M)^{2/3}(\log\log M)^{1/3}
\right).
\tag{QAL}
\]

The required quantitative modular statement follows by retaining the
parameters in Glibichuk's proof of
[Combinational properties of sets of residues modulo a prime and the
Erdős--Graham problem](https://doi.org/10.4213/mzm2708). Namely, for an
absolute \(C_1>0\), every residue \(a\bmod p\) is, for every sufficiently
large prime \(p\), of the form

\[
a\equiv\sum_{i=1}^{N}x_i^{-1}\pmod p
\]

with pairwise distinct positive integers \(x_i\) bounded by

\[
Z(p)=\exp\!\left(
C_1(\log p)^{2/3}(\log\log p)^{1/3}
\right).
\tag{MI}
\]

Here is the parameter calculation, including the distinctness issue. Put
\(L=\log p\),

\[
K=\left\lfloor\left(\frac{L}{\log L}\right)^{1/3}\right\rfloor,
\qquad
X=\left(\frac{p-1}{2K}\right)^{1/(2K-1)}.
\]

In Glibichuk's construction, \(B_K\) is the set of sums of the inverses of
\(K\) distinct primes in \([K+1,X]\). These displayed sums are distinct and
\(B_K\) is antisymmetric modulo \(p\). Indeed, after clearing the at most
\(2K\) prime denominators in a putative equality or opposite pair, the
absolute value of the numerator is at most
\(2KX^{2K-1}\leq p-1\). A congruence modulo \(p\) is therefore an equality
over the rationals; reduction modulo a prime in the symmetric difference
shows that two equal sums used the same primes, while two positive sums cannot
be opposites.

Let \(m=\pi(X)-\pi(K+1)\). Since \(m\gg X/\log X\) and \(m\gg K\), the
standard lower bound for \(\pi(x)\) gives

\[
\begin{aligned}
\log |B_K|
&=\log\binom mK\\
&\geq
K\log\!\left(\frac{cX}{\log X}\right)-\log K!\\
&=
\frac L2+\frac{L}{4K-2}-O(K\log L)
>\frac L2
\end{aligned}
\]

for all sufficiently large \(p\), because \(K^2\log L=o(L)\). Hence
\(|B_K|>\sqrt p\). Glibichuk's additive-combinatorial corollary then gives
\(8(B_KB_K)=\mathbb F_p\), where
\(B_KB_K=\{bb':b,b'\in B_K\}\) and \(8A\) denotes an eightfold sumset.
Expanding the eight products represents every residue as a sum of

\[
N=8K^2
\]

reciprocals whose denominators are at most \(X^2\), although repetitions may
still occur.

For completeness, repetitions can be removed with the exact splitting used
in the same proof. Let \(D=(2N)!\), apply the preceding representation to
\(aD\bmod p\), and initially replace every denominator \(z\) by \(Dz\).
If a denominator \(d=Dz\) occurs twice, then for any
\(1\leq j\leq N-1\),

\[
\frac2d
=
\frac1{Nd/j}+\frac1{Nd/(2N-j)}.
\tag{S}
\]

All denominators in (S) are integers. As \(j\) varies, the \(2N-2\)
candidate denominators are distinct; after removing the duplicated pair,
there are only \(N-2\) other current denominators, and each of those can
spoil at most one of the \(N-1\) candidate pairs. Some \(j\) therefore
produces two new denominators. Repeating removes every repetition without
changing the residue or the number of terms, and all final denominators are
at most \(NDX^2\). Finally,

\[
\log(NDX^2)
=O(K^2\log K)+O(L/K)
=O\!\left(L^{2/3}(\log L)^{1/3}\right),
\]

which proves (MI); this bound is \(o(\log p)\), so none of the constructed
denominators is divisible by \(p\).

Return to an \(M\)-forbidden witness \(p,E,Q,s,r\). Let \(\ell\) be the least
prime not dividing \(r\). Chebyshev's estimate for
\(\sum_{q\leq y,\ q\text{ prime}}\log q\) gives
\(\ell\ll\log(r+2)\), and in particular \(\ell<p\) for large \(p\), since
\(r<p\). Apply (MI) to the residue \(-\ell/r\bmod p\). Multiplying
all its distinct denominators by \(\ell\) gives a set, none of whose elements is
\(r\), whose inverse sum is \(-r^{-1}\bmod p\). Since \(s<p\), for all
large \(p\) the implication

\[
s\geq Z(p)^2
\quad\Longrightarrow\quad
\ell Z(p)\leq s
\]

holds. It would produce the subset forbidden by (F). Thus
\(s<Z(p)^2\). Bounded witness primes satisfy the same final estimate after
enlarging the absolute constant, and \(p\leq Q\leq M\); consequently
\(M/Q<s+1\) gives (QAL).

Thus an asymptotic forbidden pair would have to consist of consecutive
integers each divisible by a prime power larger than \(M^{1-\theta}\), for
every fixed \(\theta>0\) once \(M\) is large enough. Equivalently, their
cofactors are at most \(M^\theta\). This explains a genuine limitation of the
forbidden-pair route: a theorem giving only a fixed exponent
\(Q>M^c\), with \(c<1\), cannot by itself establish the required pair at all
large scales. What remains is an adjacent almost-linear-prime-power problem,
not merely a large-prime-factor problem.

There is a further quantitative consequence. If \(F(M)\) denotes the number
of \(M\)-forbidden integers in \([1,M]\), then

\[
F(M)=o(M).
\tag{5}
\]

Indeed, fix \(0<\theta<1/2\) and put \(Y=M^{1-\theta}\). By (AL), once \(M\)
is sufficiently large every integer counted by \(F(M)\) is divisible by a
prime power \(Q>Y\). The union bound gives

\[
\frac{F(M)}M
\leq
\sum_{\substack{Y<p^e\leq M\\p\text{ prime},\ e\geq1}}\frac1{p^e}.
\]

For \(e=1\), Mertens' theorem makes the right-hand contribution

\[
\sum_{Y<p\leq M}\frac1p
=\log\log M-\log\log Y+o(1)
=-\log(1-\theta)+o(1).
\]

The contribution of proper prime powers is \(o(1)\): the number of such
powers at most \(x\) is \(O(\sqrt{x}\log x)\), and partial summation applies.
Taking the upper limit and then letting \(\theta\) tend to zero proves (5).
Thus forbidden integers are globally sparse. The conjecture nevertheless
needs a local statement--one adjacent forbidden pair in every sufficiently
large multiplicative window--which does not follow from (5).

## The good-prime obstruction

Call a prime \(p\) *good* when at least one of

\[
\frac{p-1}{2},\qquad\frac{p+1}{2}
\]

is also prime. Suppose a counterexample has first denominator \(a=n_1\) and
last denominator \(M=n_k\), with \(a\geq13\). If a good prime \(p\) satisfies

\[
p+1\leq M\leq2p-3,
\tag{1}
\]

then a contradiction follows.

First, \(M\geq2a\). Otherwise all selected denominators lie among the \(a\)
integers \(a,\ldots,2a-1\), whose reciprocal sum is strictly smaller than
\(a(1/a)=1\). Thus \(a\leq M/2\). Condition (1) places both \(p-1\) and
\(p+1\) strictly between the endpoints \(a\) and \(M\).

The denominator \(p\) cannot be selected, because \(M<2p\) would make it the
unique selected multiple of \(p\), contrary to the prime-power obstruction.
Since two consecutive integers cannot both be absent from a sequence whose
gaps are at most 2, both \(p-1\) and \(p+1\) must therefore be selected.

Let \(q\) be a prime equal to one of the two half-neighbours of \(p\). One of
the selected integers \(p-1,p+1\) is \(2q\). Moreover, (1) implies
\(4q>M\), so the only possible selected multiples of \(q\) are
\(q,2q,3q\). If \(T\subseteq\{1,2,3\}\) is the set of their multipliers,
then \(2\in T\). Clearing denominators and reducing modulo \(q\) requires

\[
\sum_{t\in T}t^{-1}\equiv0\pmod q.
\]

The four possible rational sums have numerators \(3,9,5,11\) over the common
denominator 6. None vanishes modulo a prime \(q>11\). The chain below starts
with the exceptional values \(q=7,11\): the four numerators are already
nonzero modulo 7, while \(q=11<a\) excludes the multiplier 1 and leaves only
the numerators 3 and 5. This proves the obstruction in every case used by the
certificate.

## Controlling the last denominator

The gap condition gives \(n_i\leq a+2(i-1)\). Therefore

\[
1=\sum_{i=1}^k\frac1{n_i}
\geq\sum_{i=0}^{k-1}\frac1{a+2i}
>\frac12\int_a^{a+2k}\frac{dx}{x}.
\]

It follows that \(a+2k<e^2a\), and hence

\[
M+2\leq a+2k<e^2a.
\tag{2}
\]

For completeness, the bounded search also handles the small endpoint needed
here. If \(a\leq12\) and \(k\geq36\), then the first 36 terms alone have sum
at least

\[
\sum_{i=0}^{35}\frac1{12+2i}
=\frac{40219449830612693}{39829125407198400}>1.
\]

The exact search through \(k=100\) rules out all remaining cases, so every
counterexample would indeed have \(a\geq13\).

## Verified finite chain and consequence

For a good prime \(p\), the interval of last denominators excluded by (1) is

\[
I_p=[p+1,2p-3]\cap\mathbb Z.
\]

The certificate contains 66 good primes, begins at 13, ends at

\[
P=147573952589666836319,
\]

and verifies \(p_{j+1}\leq2p_j-3\) for every consecutive pair. Consequently
their intervals cover every integer

\[
14\leq M\leq2P-3=295147905179333672635.
\]

The verifier checks every prime below \(2^{64}\) with the deterministic
seven-base Miller--Rabin test. The entries above \(2^{64}\), and the prime
half-neighbours needed for them, are proved recursively by explicit
Pocklington certificates. It also bounds the exponential series with exact
rational arithmetic. Thirty terms give the certified implication

\[
a\leq39943925344138028689
\quad\Longrightarrow\quad
M\leq2P-3.
\]

This contradicts the interval coverage, so a counterexample must have

\[
a>39943925344138028689.
\tag{3}
\]

Finally, set \(B=39943925344138028689\). From (3), integrality and strict
increase give \(n_i\geq B+i\). Hence

\[
1\leq\sum_{i=1}^k\frac1{B+i}
<\int_B^{B+k}\frac{dx}{x}
=\log\left(1+\frac{k}{B}\right).
\]

Using the exact lower bound for \(e\) from the same 30-term series proves

\[
k\geq68634921076157089631.
\]

The good-prime strategy and finite chains were developed in the
[public discussion of Erdős problem 287](https://www.erdosproblems.com/forum/thread/287).
The repository verifier independently checks the chain and the stated numeric
consequences.

## Why this is not a complete proof

Extending a finite chain never covers arbitrarily large \(M\). A complete
proof by this route would need to show that a suitable good prime occurs in
every sufficiently large interval of the required dyadic form. That is a
difficult unresolved prime-distribution statement closely related to finding
Sophie Germain or safe primes in all such intervals. The same obstruction is
noted in the [public problem record](https://www.erdosproblems.com/287).

## Reproducible result

The program enumerates every remaining branch and uses Python `Fraction`
values, so no floating-point comparison is involved. The repository run found
no counterexample for any \(2\leq k\leq100\). At \(k=100\) it visited 38,036
search nodes and returned `witness: null`.

From the repository root, the endpoint run is:

```console
python scripts/search_unit_fraction_gaps.py --length 100
```

To repeat every length through 100 in one invocation, use:

```console
python scripts/search_unit_fraction_gaps.py --max-length 100
```

To verify the good-prime chain, its Pocklington certificates, interval
coverage, and both final bounds, use:

```console
python scripts/verify_unit_fraction_good_prime_chain.py
```

These computations establish the stated finite exclusions only. A complete
solution still needs an argument covering arbitrarily large denominators.
