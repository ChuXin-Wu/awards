# JSP-000244: exact finite verification and a good-prime certificate

[Problem record](../catalog-0201-0300.md#JSP-000244) · [Search program](../../scripts/search_unit_fraction_gaps.py) · [Certificate verifier](../../scripts/verify_unit_fraction_good_prime_chain.py)

This note proves that every fixed denominator count reduces to a finite exact
search, records the repository's verification through 100 denominators, and
checks a finite good-prime certificate. It also develops an exact
forbidden-pair reduction and several unconditional asymptotic restrictions on
any counterexample. The certified finite bounds are

\[
n_1>39943925344138028689
\quad\text{and}\quad
k\geq68634921076157089631.
\]

This is a much stronger finite exclusion, but it does **not** prove the
unrestricted conjecture.

## Statement

The conjecture asks whether every representation

\[
1=\frac1{n_1}+\cdots+\frac1{n_k},\qquad 1<n_1<\cdots<n_k,
\]

has some consecutive gap at least 3.

## Finite-reduction lemma

Fix an integer \(k\geq2\). If a counterexample of length \(k\) exists, it is
among the finitely many sequences obtained by choosing

\[
n_1\in\{2,\ldots,k-1\}
\quad\text{and}\quad
(n_{i+1}-n_i)_{i=1}^{k-1}\in\{1,2\}^{k-1}.
\]

**Proof.** In a counterexample every gap is a positive integer smaller than 3,
so every gap is 1 or 2. It remains to bound the first denominator. If
\(n_1\geq k\), then \(1/n_i\leq1/n_1\) for every \(i\), with a strict
inequality for every \(i>1\). Therefore

\[
\sum_{i=1}^k\frac1{n_i}<\frac{k}{n_1}\leq1,
\]

contradicting the required equality. Hence \(2\leq n_1<k\), and the stated
finite enumeration is exhaustive. \(\square\)

## Sound pruning lemma

Suppose a partial candidate currently ends at denominator \(c\), has reciprocal
sum \(S\), and still needs \(r\) denominators. For the \(j\)th future
denominator \(m_j\), the gap restriction gives

\[
c+j\leq m_j\leq c+2j.
\]

Consequently every completion has its remaining sum in the exact interval

\[
\sum_{j=1}^r\frac1{c+2j}
\ \leq\
\sum_{j=1}^r\frac1{m_j}
\ \leq\
\sum_{j=1}^r\frac1{c+j}.
\]

It is therefore sound to discard a branch when the upper endpoint added to
\(S\) is below 1, or when the lower endpoint added to \(S\) is above 1. Equality
is not pruned. These are exactly the two pruning rules used by the program.

## Prime-power obstruction

Let \(m_1,\ldots,m_s\) be positive integers whose reciprocal sum is an
integer. For every prime \(p\), the maximum of

\[
v_p(m_1),\ldots,v_p(m_s)
\]

cannot be positive and attained exactly once.

**Proof.** Let \(L=\operatorname{lcm}(m_1,\ldots,m_s)\), and suppose the
positive maximum \(e\) is attained only at \(m_j\). After multiplying the
reciprocal sum by \(L\), every term \(L/m_i\) with \(i\ne j\) is divisible by
\(p\), while \(L/m_j\) is not. Their sum is therefore nonzero modulo \(p\).
The other side is an integer multiple of \(L\), hence is zero modulo \(p\), a
contradiction. \(\square\)

This gives a third sound pruning rule. If a partial branch has a unique
largest \(p\)-power and no future denominator in the full reachable interval
can be divisible by that power, every completion retains a unique maximum and
cannot sum to 1. A future denominator with a still higher \(p\)-valuation is
also a multiple of the current power, so the test does not discard that
possibility.

The unique-maximum obstruction alone cannot settle the conjecture. For an
explicit certificate, let

\[
S=[7,62]\setminus\{32,37,41,43,47,49,53,59,61\}.
\]

The omitted integers are never consecutive, so the ordered elements of \(S\)
have gaps at most 2. Nevertheless no prime has a positive maximal valuation
attained exactly once on \(S\). For \(p=2,3,5\), the respective top layers are
\(\{16,48\}\), \(\{27,54\}\), and \(\{25,50\}\). The sole multiple \(49\)
of \(7^2\) is omitted, leaving several multiples of 7 in the top layer. Every
prime from 11 through 31 has at least two selected multiples, while every
prime from 37 through 61 is itself omitted and has no selected multiple.
Primes above 61 divide no element of \(S\). Thus any proof must use more than
the multiplicity of the top layer; the residue carried by that layer matters.

## Full p-adic congruence

The search now uses the following stronger form of the same obstruction. Let
\(e=\max_i v_p(m_i)>0\), and write every denominator in the top layer as
\(m_i=p^e t_i\), where \(p\nmid t_i\). If the reciprocal sum is an integer,
then

\[
\sum_{v_p(m_i)=e}t_i^{-1}\equiv0\pmod p.
\tag{TL}
\]

Indeed, put \(L=\operatorname{lcm}(m_1,\ldots,m_s)\) and \(C=L/p^e\).
After multiplying the reciprocal sum by \(L\) and reducing modulo \(p\), all
terms below the top layer vanish, while a top-layer term becomes
\(C/t_i\equiv C t_i^{-1}\pmod p\). Since \(p\nmid C\), cancellation of \(C\)
gives (TL).

The implementation retains more than this first congruence digit. For every
denominator divisible by \(p\), write
\(m_i=p^{e_i}t_i\) with \(p\nmid t_i\), where
\(e=\max_i e_i\). The same calculation before reduction modulo \(p\) gives

\[
\sum_{e_i>0}p^{e-e_i}t_i^{-1}\equiv0\pmod {p^e}.
\tag{PA}
\]

Equation (TL) is the reduction of (PA) modulo \(p\). Keeping (PA) also retains
the carries from lower \(p\)-adic layers.

For a partial branch, suppose no integer in the full reachable future interval
is divisible by \(p^{e+1}\). The current top layer will then remain the top
layer. The program computes every residue obtainable by choosing an arbitrary
subset of all reachable future multiples of \(p\), normalized as in (PA). It
deliberately ignores the gap condition and the number of remaining positions,
so this is an over-approximation of all genuine completions. If even this
larger residue set cannot cancel the current residue in (PA), pruning the
branch is sound. If a higher layer is reachable, or if a deliberately imposed
residue-set size cap is exceeded, the program keeps the branch.

The earlier unique-maximum rule is the special case in which the current top
layer has one term and there is no reachable term in the same or a higher
layer. Retaining the complete congruence is substantially stronger. For
example, the two top-layer multiples \(31\) and \(62\) do not have a unique
maximum 31-adic valuation, but their cofactor-reciprocal sum is
\(1+1/2\not\equiv0\pmod {31}\).

## An exact forbidden-pair reduction

The congruence gives a precise sufficient condition that would finish the
unbounded problem if it could be established at every scale. Fix a prospective
largest denominator \(M\). Call \(n\leq M\) *\(M\)-forbidden* if there are a
prime \(p\) and an exponent \(E\geq1\) such that, on writing

\[
p^E\parallel n,\qquad p^{E+1}>M,\qquad
s=\left\lfloor\frac{M}{p^E}\right\rfloor,\qquad
r=\frac{n}{p^E},
\]

no subset \(T\subseteq\{1,\ldots,s\}\) containing \(r\) satisfies

\[
\sum_{t\in T}t^{-1}\equiv0\pmod p.
\tag{F}
\]

Every denominator occurring in an integer reciprocal sum whose largest
denominator is at most \(M\) is not \(M\)-forbidden. Indeed, if an
\(M\)-forbidden \(n\) were selected, then \(p^{E+1}>M\) would make \(E\) the
largest selected \(p\)-adic valuation. The selected top-layer denominators
would be \(p^Et\) for a subset \(T\subseteq\{1,\ldots,s\}\) containing \(r\).
The top-layer congruence (TL) would give (F), contrary to the definition.
Notice that \(s<p\), so all the displayed inverses exist modulo \(p\).

There is also an endpoint bound independent of the gap condition. If a
counterexample starts at \(a\) and ends at \(M\), then

\[
1\leq\sum_{n=a}^{M}\frac1n
<\int_{a-1}^{M}\frac{dx}{x}
=\log\frac{M}{a-1}.
\]

Consequently \(M>e(a-1)\), and hence

\[
a\leq\left\lceil\frac{M}{e}\right\rceil.
\tag{EP}
\]

It follows that the original conjecture would be proved if one could show that
for every sufficiently large \(M\), the interval

\[
\left[\left\lceil\frac{M}{e}\right\rceil,M\right]
\]

contains two consecutive \(M\)-forbidden integers. Both integers cannot be
selected, while the gap condition says that every two consecutive integers
between the selected endpoints \(a\) and \(M\) contain a selected denominator.
The finitely many smaller values of \(M\) could then be checked exactly.

This is an unconditional reduction, not an assertion that the required pair
always exists. Every nonexceptional link in the good-prime obstruction below
constructs such a pair: the large prime \(p\) is forbidden, and one of
\(p-1,p+1\) is \(2q\), whose multiplier \(2\) belongs to no zero-sum subset of
the available multipliers modulo \(q\). The initial \(q=11\) case is a small
exception to the global definition above; the good-prime proof handles it
using the independently established lower endpoint \(a\geq13\).

### An elementary logarithmic-cofactor criterion

The subset condition (F) has a useful closed-form sufficient test. Put

\[
L_s=\operatorname{lcm}(1,\ldots,s),
\qquad
A_s=L_s\sum_{t=1}^{s}\frac1t.
\]

Both quantities are integers. If \(p\) is prime, \(s<p\), and \(p>A_s\),
then no nonempty subset \(T\subseteq\{1,\ldots,s\}\) has

\[
\sum_{t\in T}t^{-1}\equiv0\pmod p.
\tag{LC}
\]

Indeed, after multiplication by \(L_s\), the sum in (LC) has an integer
numerator between 1 and \(A_s<p\); also \(p\nmid L_s\). It therefore cannot
vanish modulo \(p\).

Consequently, if \(s=\lfloor M/p\rfloor<p\) and \(p>A_s\), every multiple
\(pr\leq M\) is \(M\)-forbidden. Indeed, \(r\leq s<p\), while
\(M<p(s+1)\leq p^2\); hence \(p\parallel pr\), and one may use \(E=1\) in
(F). The required subset would be nonempty because it contains \(r\). This
includes, but is not limited to, the fixed small-multiplier tests used in the
good-prime argument.

The prime number theorem in the equivalent form
\(\log L_s=\psi(s)=s+o(s)\), together with
\(H_s=\log s+O(1)\), gives

\[
\log A_s=s+o(s).
\]

Thus, for every fixed \(\eta>0\) and all sufficiently large \(p\), the simple
condition

\[
\left\lfloor\frac Mp\right\rfloor\leq(1-\eta)\log p
\tag{LCF}
\]

makes every multiple of \(p\) up to \(M\) forbidden. In particular, a full
proof would follow if every sufficiently large interval
\([\lceil M/e\rceil,M]\) contained consecutive integers each possessing a
prime divisor satisfying (LCF). Establishing such adjacent almost-primes in
every multiplicative interval is itself beyond the presently used prime
distribution input; (LCF) is a rigorous sufficient condition, not an assertion
that such a pair always exists.

### Forbidden multiples force logarithmically many unit gaps

The multiples supplied by (LCF) have a further global consequence. Let
\(S=\{n_1,\ldots,n_k\}\) be a putative counterexample with endpoints \(a,M\),
and let \(g\) be the number of its consecutive gaps equal to 1. Suppose that
\(p\) is an odd prime for which every multiple of \(p\) up to \(M\) is
\(M\)-forbidden. Define

\[
J_p=\left\{j\geq1:
a\leq(2j-1)p-1,
\quad 2jp+1\leq M
\right\}.
\]

Then

\[
g\geq |J_p|.
\tag{UG}
\]

To see this, partition the integers into the two-element blocks
\(B_u=\{2u,2u+1\}\). Every block wholly between the endpoints contains a
selected denominator, since two consecutive omissions are impossible. Call a
block \(E\), \(O\), or \(D\) according as only its even member, only its odd
member, or both members are selected. Two consecutive non-\(D\) blocks cannot
make a transition \(E\mathbin{\to}O\): that would omit the consecutive
integers \(2u+1,2u+2\).

For \(j\in J_p\), the forbidden odd integer \((2j-1)p\) is omitted and its
even predecessor is selected. Thus the block

\[
u_j=\frac{(2j-1)p-1}{2}
\]

has type \(E\). The forbidden even integer \(2jp\) is omitted and its odd
successor is selected, so the block \(v_j=jp\) has type \(O\). There must
therefore be a \(D\)-block strictly between \(u_j\) and \(v_j\); if the two
blocks are consecutive, the asserted transition is itself impossible. The
open block intervals \((u_j,v_j)\) are pairwise disjoint, because

\[
u_{j+1}=jp+\frac{p-1}{2}>v_j.
\]

Hence different \(j\)'s force different \(D\)-blocks, and every \(D\)-block
contributes a unit gap. This proves (UG).

This gives an unconditional growing cost. By the prime number theorem, for
all sufficiently large \(M\) there is a prime

\[
\frac{2M}{\log M}\leq p\leq\frac{3M}{\log M}.
\]

Here \(\lfloor M/p\rfloor\leq\tfrac12\log M\leq0.6\log p\) for all
sufficiently large \(M\), so (LCF), with \(\eta=0.4\), makes every multiple
of \(p\) forbidden. The endpoint bound (EP) and the elementary estimate

\[
|J_p|\geq\frac{M-a}{2p}-2
\]

then imply, after increasing the absolute threshold if necessary,

\[
g\geq\frac1{12}\log M.
\tag{LG}
\]

The unit gaps slightly sharpen the multiplicative endpoint restriction. Since

\[
M-a=2(k-1)-g,
\]

we have \(a+2k=M+g+2\). As in the endpoint estimate below,

\[
1=\sum_{i=1}^k\frac1{n_i}
\geq\sum_{i=0}^{k-1}\frac1{a+2i}
>\frac12\log\frac{a+2k}{a}.
\]

Consequently every sufficiently large counterexample would satisfy

\[
M+g+2<e^2a,
\qquad
a>\frac{M+(\log M)/12+2}{e^2}.
\tag{ER}
\]

The gain in (ER) is only additive in \(\log M\), so it does not by itself
close the problem. It records a genuine global cost of the forbidden
multiples that is absent from the adjacent-forbidden-pair reduction.

The number of unit gaps can in fact be forced to grow polynomially if one
uses a deep theorem on primes in short intervals. Baker, Harman, and Pintz
proved that, for all sufficiently large \(x\),

\[
[x-x^{0.525},x]
\]

contains a prime; see
[*The Difference Between Consecutive Primes, II*](https://doi.org/10.1112/plms/83.3.532),
Theorem 1. Apply this result inside the fixed interval

\[
I=\left[\frac{3M}{4},\frac{7M}{8}\right].
\]

Split the selected denominators into their maximal *parity runs*, meaning
maximal consecutive subsequences all of whose gaps are 2. There are exactly
\(g+1\) such runs, and each run selects every integer of one parity in its
convex hull.

An odd parity run cannot have an intersection of length \(\gg M^{0.525}\)
with \(I\). Otherwise the short-interval theorem supplies an odd prime
\(p\) in that intersection. Since \(p>M/2\), the selected denominator \(p\)
would be the unique selected multiple of \(p\) up to \(M\), contrary to the
prime-power obstruction.

An even parity run satisfies the same length bound. Indeed, halve a long
subinterval of its intersection with \(I\) and apply the theorem there. This
gives a prime

\[
\frac{3M}{8}\leq q\leq\frac{7M}{16}
\]

for which \(2q\) lies in the even run. Here \(\lfloor M/q\rfloor=2\), so the
selected top \(q\)-adic layer has multiplier set either \(\{2\}\) or
\(\{1,2\}\). Its inverse sum is respectively \(1/2\) or \(3/2\), neither of
which is zero modulo the large prime \(q\), contradicting (TL).

The convex hulls of the \(g+1\) runs, together with their \(g\) unit
junctions, cover \(I\). Since every such hull meets \(I\) in length
\(O(M^{0.525})\), this proves the stronger local statement

\[
\text{every subinterval of }I\text{ of length }C M^{0.525}
\text{ contains a unit gap}
\tag{PL}
\]

for some absolute \(C\) and all sufficiently large \(M\). The fixed length
\(|I|=M/8\) then gives

\[
g\gg M^{0.475}.
\tag{PG}
\]

The total number of unit gaps admits a substantially stronger bound than (PG).
Stadlmann's unconditional mean-square prime-gap theorem
([*On the mean square gap between primes*](https://arxiv.org/abs/2212.10867),
Theorem 1) states that, for every fixed \(\varepsilon>0\),

\[
\sum_{p_n\leq x}(p_{n+1}-p_n)^2
\ll_\varepsilon x^{1.23+\varepsilon}.
\tag{MS}
\]

Let \(\ell_j\) be the length of the intersection with \(I\) of the convex
hull of the \(j\)-th parity run. Every odd run lies inside a gap between
consecutive primes. If several disjoint odd runs lie inside the same prime
gap, the sum of the squares of their lengths is at most the square of that
gap. After division by 2, the identical statement holds for the even runs and
the gaps between consecutive primes \(q\), because an even run contains no
integer \(2q\). Thus (MS) gives

\[
\sum_{j=1}^{g+1}\ell_j^2
\ll_\varepsilon M^{1.23+\varepsilon}.
\]

The run hulls and their unit junctions cover \(I\), so

\[
\frac M8\leq \sum_{j=1}^{g+1}\ell_j+g.
\]

If \(g\geq M/16\) there is nothing to prove. Otherwise Cauchy--Schwarz and
the preceding two displays yield, after renaming \(\varepsilon\),

\[
g\gg_\varepsilon M^{0.77-\varepsilon}
\qquad(\varepsilon>0).
\tag{MG}
\]

The same argument is local. Let \(J\subseteq I\) be any interval of length
\(H\geq1\), and let \(G(J)\) be the number of unit junctions meeting \(J\).
Intersecting the parity runs with \(J\) produces at most \(G(J)+1\) run
pieces, of lengths \(\ell_1,\ldots,\ell_r\). The prime-gap argument above
still gives

\[
\sum_{j=1}^{r}\ell_j^2
\ll_\varepsilon M^{1.23+\varepsilon}.
\]

The run pieces and the unit junctions cover \(J\). If \(G(J)\geq H/2\), the
following bound is immediate; otherwise
\(\sum_j\ell_j\geq H/2\), and Cauchy--Schwarz gives it. After renaming
\(\varepsilon\),

\[
G(J)+1
\gg_\varepsilon
\frac{H^2}{M^{1.23+\varepsilon}}.
\tag{ML}
\]

Thus the polynomially many unit gaps cannot all be concentrated in a short
part of the upper interval. For example, every subinterval of \(I\) whose
length is a fixed positive proportion of \(M\) contains
\(\gg_\varepsilon M^{0.77-\varepsilon}\) unit gaps. At the shorter scale,
(PL) remains stronger and guarantees at
least one unit gap in every interval of length \(CM^{0.525}\).

An almost-all short-interval theorem gives a stronger exponent. Theorem 1.1
of Li,
[*Primes in almost all short intervals*](https://arxiv.org/abs/2407.05651),
already gives the exponent \(1/21+\eta\). A subsequent unpublished manuscript
by the same author,
[*Primes in almost all short intervals III*](https://runbolicarey.com/assets/downloads/Primes_in_almost_all_short_intervals_III.pdf),
states the following stronger form sufficient here. For fixed \(\eta>0\),
every fixed sufficiently large \(B\), and all sufficiently large \(X\), all
but \(O_{\eta,B}(X(\log X)^{-B})\) integers \(n\in[X,2X]\) have a prime in

\[
[n-n^{1/24+\eta},n].
\tag{AI}
\]

Put \(\theta=1/24+\eta\) and \(H=C_\eta M^\theta\), with a fixed constant
large enough to absorb the fixed rescalings below. If an odd parity-run piece
inside \(I\) has length \(\ell\), then each of the
\((\ell-H-O(1))_+\) integer right endpoints whose backward short interval in
(AI) stays inside that piece is exceptional. These sets of endpoints are
disjoint for different odd pieces. Hence

\[
\sum_{\substack{j\\ m\text{ odd}}}(\ell_j-H-O(1))_+
\ll_{\eta,B}\frac{M}{(\log M)^B}.
\]

For an even run, divide its intersection with \(I\) by 2. The resulting
interval lies in \([3M/8,7M/16]\), contains no primes, and has half the
original length. Applying (AI) at that scale gives, after changing the fixed
constant in \(H\),

\[
\sum_{\substack{j\\ m\text{ even}}}(\ell_j-H-O(1))_+
\ll_{\eta,B}\frac{M}{(\log M)^B}.
\]

There are at most \(g+1\) run pieces, and their hulls together with the unit
junctions cover \(I\). Therefore

\[
\frac M8
\leq C_\eta(g+1)M^\theta
+O_{\eta,B}\!\left(\frac{M}{(\log M)^B}\right)+g.
\]

Choose any fixed \(B>0\). The error is \(o(M)\), while \(M^\theta\to\infty\),
so this proves, after renaming \(\eta\),

\[
g\gg_\varepsilon M^{23/24-\varepsilon}
\qquad(\varepsilon>0).
\tag{AG}
\]

The same proof applies to every subinterval of \(I\) whose length is a fixed
positive proportion of \(M\); thus the unit gaps counted in (AG) are
macroscopically distributed, not confined to one end of \(I\).

In particular, (ER) improves, for every fixed \(\varepsilon>0\), to

\[
a>\frac{M+c_\varepsilon M^{23/24-\varepsilon}+2}{e^2}
\]

for some \(c_\varepsilon>0\) and all sufficiently large counterexamples. This
is much stronger than (LG), but it is still sublinear and therefore does not
remove the limiting phase \((c,\gamma)=(e^{-2},0)\).

There is a sharper two-parameter restriction obtained by retaining the exact
number of unit gaps. Write

\[
n_{i+1}-n_i\in\{1,2\},
\qquad
g=\#\{i:n_{i+1}-n_i=1\}.
\]

Among all such gap words with fixed \(a,k,g\), the reciprocal sum is largest
when the \(g\) unit gaps come first and smallest when they come last. Indeed,
interchanging an adjacent pair of gaps \((2,1)\) with \((1,2)\) decreases the
single denominator between them by 1 and leaves every later denominator
unchanged. Repeating this interchange proves the assertion. Consequently

\[
\begin{aligned}
&\sum_{i=0}^{k-1-g}\frac1{a+2i}
 +\sum_{j=1}^{g}\frac1{M-g+j}
\\
&\hspace{35mm}\leq 1 \leq
\sum_{i=0}^{g}\frac1{a+i}
 +\sum_{j=1}^{k-1-g}\frac1{a+g+2j}.
\end{aligned}
\tag{GR}
\]

This has a clean asymptotic form. Along any sequence of counterexamples for
which

\[
\frac aM\longrightarrow c,
\qquad
\frac gM\longrightarrow\gamma,
\]

the integral estimates for the two sides of (GR) give

\[
\frac12\log\frac1{c(1-\gamma)}
\leq1\leq
\frac12\log\frac{c+\gamma}{c^2}.
\]

Equivalently, every such limit point lies in the phase region

\[
e^{-2}\leq c\leq e^{-1},
\qquad
e^2c^2-c\leq\gamma\leq1-\frac{e^{-2}}c.
\tag{PR}
\]

Here \(c\leq e^{-1}\) is (EP), while the other bounds follow from the two
displayed logarithmic inequalities. The endpoints of the region are sharp at
the level of real asymptotics: \((c,\gamma)=(e^{-2},0)\) corresponds to an
alternating gap pattern, and
\((c,\gamma)=(e^{-1},1-e^{-1})\) to consecutive denominators. Exact equality
of the rational sum remains subject to the \(p\)-adic obstructions. Thus (PR)
does not settle the problem, but it rules out every putative asymptotic shape
outside an explicit compact region and strengthens the one-sided estimate
(ER) whenever \(g\) has positive linear density.

### Activating a large-prime layer is expensive

There is also a quantitative restriction on selected, rather than forbidden,
multiples. Let \(p>\sqrt M\) be prime, put \(s=\lfloor M/p\rfloor\), and let

\[
T_p=\{r\leq s:pr\in S\},
\qquad h=|T_p|.
\]

If \(h>0\), then

\[
p\leq h s^{h-1}.
\tag{LA}
\]

Indeed, \(p^2>M\), so the selected multiples \(pr\) form the complete top
\(p\)-adic layer. By (TL),

\[
\sum_{r\in T_p}r^{-1}\equiv0\pmod p.
\]

After multiplying by \(D=\prod_{r\in T_p}r\), the positive integer

\[
N=\sum_{r\in T_p}\frac D r
\]

is divisible by \(p\), while \(N\leq h s^{h-1}\). This proves (LA). In
particular, when \(s\geq2\), the inequalities \(h\leq s\) and
\(h s^{h-1}\leq s^h\) give

\[
h\geq\left\lceil\frac{\log p}{\log s}\right\rceil.
\tag{LB}
\]

The same calculation gives an exact compression identity, not just an
inequality. Write \(N=m_p p\), where \(m_p\) is a positive integer. Then

\[
\sum_{r\in T_p}\frac1{pr}=\frac{m_p}{D},
\qquad
1\leq m_p\leq\frac{h s^{h-1}}p.
\tag{CP}
\]

The upper bound is the estimate for \(N/p\) used in (LA), and positivity gives
the lower bound. Thus the contribution of a complete active layer can be
rewritten with the large prime \(p\) removed from its denominator. In the
first nontrivial case \(T_p=\{x,y,z\}\), this says exactly

\[
xy+xz+yz=m_p p,
\qquad
\frac1{px}+\frac1{py}+\frac1{pz}=\frac{m_p}{xyz}.
\tag{CT}
\]

Compression is useful structural information, but it does not preserve the
unit-fraction or gap conditions: the new denominator \(D\) is a product of
cofactors and can be much larger than \(M\). Consequently (CP) alone is not
an induction on the largest denominator.

Thus a large-prime layer is either unused or must be activated by many of its
multiples. For example, if \(p>\sqrt{2M}\), then \(p>2s\), so a nonempty
layer has at least three selected multiples. Layers belonging to distinct
primes above \(\sqrt M\) are disjoint, since their product exceeds \(M\).
More generally, for every integer \(j\geq2\),

\[
p>j^{1/j}M^{1-1/j}
\quad\Longrightarrow\quad
|T_p|\geq j+1
\tag{LH}
\]

whenever \(T_p\) is nonempty. Indeed, if \(h=|T_p|\leq j\), then (LA) and
\(s\leq M/p\) give

\[
p\leq h s^{h-1}\leq j\left(\frac Mp\right)^{j-1},
\]

contrary to the displayed hypothesis after taking \(j\)th powers.
These facts expose additional rigidity beyond merely ruling out a unique
maximum valuation, but an argument converting their aggregate activation cost
into a contradiction is still required.

The activation is forced on a linear scale. Let

\[
S_{>}=\{n\in S:P^+(n)>\sqrt M\},
\]

where \(P^+(n)\) is the largest prime factor of \(n\). Then every sufficiently
large counterexample satisfies

\[
|S_{>}|
\geq
\left(\log 2-\frac12\right)(M-a)+\frac g2+o(M)
\geq
\left(\log 2-\frac12\right)\left(1-\frac1e\right)M+o(M).
\tag{RA}
\]

Here is an elementary derivation. Uniformly for \(x=cM+O(1)\), with \(c\)
in any fixed compact subinterval of \((0,1]\), an integer \(n\leq x\) with
\(P^+(n)>\sqrt M\) has a unique expression \(n=pr\), where
\(p>\sqrt M\) is prime. Mertens' estimate for reciprocal primes therefore
gives

\[
\begin{aligned}
\#\{n\leq x:P^+(n)>\sqrt M\}
&=\sum_{\sqrt M<p\leq x}\left\lfloor\frac{x}{p}\right\rfloor\\
&=x\sum_{\sqrt M<p\leq x}\frac1p+O(\pi(x))\\
&=(\log 2)x+o(M).
\end{aligned}
\]

The endpoint bounds put \(a/M\) in a fixed compact subinterval of
\((0,1)\). Subtracting the estimates at \(x=M\) and \(x=a-1\) shows that
the interval \([a,M]\) contains

\[
(\log 2)(M-a)+o(M)
\]

integers with largest prime factor above \(\sqrt M\), and hence only
\((1-\log 2)(M-a)+o(M)\) other integers. On the other hand, the exact relation
between the two gap sizes gives

\[
|S|=k=\frac{M-a+g}{2}+1.
\]

Even if every available integer with largest prime factor at most \(\sqrt M\)
were selected, subtraction yields the first inequality in (RA). The second
follows from (EP).

The same calculation gives a useful threshold family. For every fixed
\(1/2<\beta<1\), one has

\[
\#\{n\in S:P^+(n)>M^\beta\}
\geq
\left(-\log\beta-\frac12\right)(M-a)+\frac g2+o(M).
\tag{RT}
\]

Indeed, replacing \(\sqrt M\) by \(M^\beta\) in the reciprocal-prime
calculation changes the density \(\log 2\) to
\(\log(1/\beta)=-\log\beta\). Unlike the estimate that discards the unit-gap
count, (RT) can remain positive beyond \(e^{-1/2}\).

More precisely, along a sequence with \(a/M\to c\) and \(g/M\to\gamma\), put

\[
r_\beta(c,\gamma)
=\left(-\log\beta-\frac12\right)(1-c)+\frac\gamma2,
\qquad
B(c,\gamma)
=\exp\!\left(-\frac12+\frac{\gamma}{2(1-c)}\right).
\tag{RB}
\]

Then \(r_\beta(c,\gamma)>0\) precisely when \(\beta<B(c,\gamma)\), and (RT)
forces at least \(r_\beta(c,\gamma)M+o(M)\) selected denominators above that
prime-factor threshold. Since \(0\leq\gamma\leq1-c\), the moving threshold
lies between \(e^{-1/2}\) and 1.

Combining this observation with the phase region (PR) gives a restriction
depending only on \(c\):

\[
B(c,\gamma)\geq
B_0(c):=
\exp\!\left(
-\frac12+\frac{e^2c^2-c}{2(1-c)}
\right).
\tag{BT}
\]

The exponent defining \(B_0\) is strictly increasing on
\([e^{-2},e^{-1}]\), since the derivative of its nonconstant numerator ratio
has the sign of \(e^2c(2-c)-1>0\). Thus the thresholds below are unique.
For example, let \(c_4=0.2239859452\ldots\) be the unique number in
\((e^{-2},e^{-1})\) satisfying \(B_0(c_4)=2/3\). If \(c>c_4\), one may choose
\(2/3<\beta<B_0(c)\). Equations (RT) and (LH), with \(j=3\), then force
linearly many selected denominators with prime factor above \(M^\beta\), each
belonging to a layer of at least four selected multiples. More generally,
whenever \(B_0(c)>1-1/j\), the same argument reaches the \((j+1)\)-term level.
Thus the earlier fixed threshold \(e^{-1/2}\) is a genuine obstruction only
near the alternating endpoint \(c=e^{-2}\), not throughout the phase region.

There is an even stronger aggregate consequence. Whenever
\(r_\beta(c,\gamma)>0\), every fixed
\(0<\lambda<r_\beta(c,\gamma)\) satisfies

\[
\#\left\{n\in S:
P^+(n)>M^\beta,\ |T_{P^+(n)}|>\lambda\log M
\right\}
\geq\left(r_\beta(c,\gamma)-\lambda\right)M+o(M).
\tag{RL}
\]

Indeed, there are at most \(\pi(M)=(1+o(1))M/\log M\) possible prime layers.
All layers having at most \(\lambda\log M\) selected multipliers therefore
contain at most \(\lambda M+o(M)\) selected terms in total. Subtracting this
from (RT) proves (RL). In particular, linearly many selected denominators,
carrying at least \(r_\beta(c,\gamma)-\lambda+o(1)\) reciprocal mass, lie in
layers whose cardinalities themselves grow logarithmically. Formula (CP)
compresses each such layer exactly. The remaining difficulty is to retain
enough of the global gap information after these separate compressions.

In fact a positive proportion of the multiplier interval can be forced, not
just logarithmically many multipliers. Put \(d_\beta=-\log\beta\). For every
fixed

\[
0<\kappa<\frac{r_\beta(c,\gamma)}{d_\beta},
\]

one has

\[
\#\left\{n\in S:
P^+(n)>M^\beta,\
|T_{P^+(n)}|\geq
\kappa\left\lfloor\frac{M}{P^+(n)}\right\rfloor
\right\}
\geq
\left(r_\beta(c,\gamma)-\kappa d_\beta\right)M+o(M).
\tag{RD}
\]

To prove this, call a prime layer *sparse* when
\(h=|T_p|<\kappa s\), where \(s=\lfloor M/p\rfloor\). The total number of
selected terms in all sparse layers above \(M^\beta\) is at most

\[
\kappa\sum_{M^\beta<p\leq M}\left\lfloor\frac Mp\right\rfloor
=\kappa d_\beta M+o(M)
\]

by the same reciprocal-prime estimate used in (RT). Subtracting this from
(RT) proves (RD). Hence linearly many selected denominators lie in layers
occupying a fixed positive fraction of the multipliers
\(1\leq r\leq\lfloor M/p\rfloor\). Since
the layers with \(p>M/(L\log M)\) contain only \(o(M)\) integers in total for
each fixed \(L\), (RD) also recovers the logarithmic-cardinality conclusion
(RL) after discarding \(o(M)\) terms.

There is a uniform numerical consequence, independent of the limiting phase.
Put

\[
\kappa_*=
\frac{(\log2-1/2)(1-e^{-2})}{\log2}
=0.2409409673\ldots.
\tag{KD}
\]

For every fixed \(0<\kappa<\kappa_*\), one may choose a fixed
\(\beta_\kappa>1/2\) sufficiently close to \(1/2\) so that (RD) gives a
positive uniform linear lower bound. Indeed, write \(d=-\log\beta\). By the
lower phase bound \(\gamma\geq e^2c^2-c\) in (PR), the coefficient left after
discarding the layers with \(h<\kappa s\) is bounded below by

\[
F_{\beta,\kappa}(c)=
\left(d-\frac12\right)(1-c)
+\frac{e^2c^2-c}{2}-\kappa d,
\qquad e^{-2}\leq c\leq e^{-1}.
\]

At \(\beta=1/2\), the derivative of the numerator before the term
\(-\kappa\log2\) is

\[
e^2c-\log2>0
\qquad(e^{-2}\leq c\leq e^{-1}),
\]

so the minimum occurs at \(c=e^{-2}\), where it equals
\((\kappa_*-\kappa)\log2>0\). Compactness and continuity therefore give a
fixed \(\beta_\kappa>1/2\) and a fixed

\[
\delta_\kappa=
\min_{e^{-2}\leq c\leq e^{-1}}
F_{\beta_\kappa,\kappa}(c)>0.
\]

This lower bound is uniform, not merely subsequential: otherwise a failing
sequence would have a subsequence on which \(a/M\) and \(g/M\) converge, and
its limiting phase would satisfy (PR), contradicting the displayed positive
minimum. Equations (PR), (RT), and the proof of (RD) therefore show that at least
\(\delta_\kappa M+o(M)\) selected denominators lie in layers with
\(|T_p|\geq\kappa\lfloor M/p\rfloor\). Thus every sufficiently large
counterexample would contain a linear collection of terms in uniformly dense
large-prime layers, with any fixed density below
\(0.2409409673\ldots\), even in the limiting alternating phase.

The density conclusion (RD) is substantially stronger than the pointwise
activation inequality, but a dense subset of the inverses
\(\{1^{-1},\ldots,s^{-1}\}\bmod p\) can still have sum zero. A completion
must use how the gap word couples these dense subsets for different primes;
their densities alone do not contradict (TL).

Moreover, only \(o(M)\) integers up to \(M\) have largest prime factor in
the narrow range

\[
\sqrt M<P^+(n)\leq\sqrt{2M}.
\]

Indeed, their number is at most

\[
M\sum_{\sqrt M<p\leq\sqrt{2M}}\frac1p
=O\left(\frac{M}{\log M}\right)
=o(M).
\]

Consequently (RA) remains true, with the same main term, after restricting
to selected integers whose associated prime is greater than \(\sqrt{2M}\).
For each such prime the corresponding nonempty layer contains at least three
selected multiples by (LA), and layers for different primes are disjoint.
In particular these activated layers alone contribute at least

\[
\left(\log 2-\frac12\right)\left(1-\frac aM\right)
+\frac{g}{2M}+o(1)
\geq
\left(\log 2-\frac12\right)\left(1-\frac1e\right)+o(1)
=0.122092\ldots+o(1)
\tag{RM}
\]

to the reciprocal sum, since every selected denominator is at most \(M\).
This is a constant-scale restriction, unlike (LG), but it is still compatible
with a total reciprocal sum of 1. A completion needs to exploit the modular
shape of the active subsets, not just their cardinality or reciprocal mass.

There is a density-one sharpening of the constant in (LCF). For a fixed
\(s\), call a prime \(p>s\) exceptional if some nonempty
\(T\subseteq\{1,\ldots,s\}\) has zero inverse sum modulo \(p\). For each such
\(T\), put

\[
B_T=L_s\sum_{t\in T}\frac1t.
\]

Then \(1\leq B_T\leq A_s\), and every exceptional \(p\) divides at least one
\(B_T\), because \(p\nmid L_s\). Consequently

\[
\sum_{\substack{p>s\\p\text{ exceptional}}}\log p
\leq
\sum_{\varnothing\ne T\subseteq\{1,\ldots,s\}}\log B_T
\leq
2^s\log A_s
=(1+o(1))s2^s.
\tag{DE}
\]

Fix \(c<1/\log 2\), let \(X\) tend to infinity, and put
\(s_X=\lfloor c\log(2X)\rfloor\). If \(X\leq p\leq2X\) and some nonempty
subset of \(\{1,\ldots,\lfloor c\log p\rfloor\}\) has zero inverse sum
modulo \(p\), then \(p\) is exceptional for \(s_X\). By (DE), the number of
such primes is

\[
O(2^{s_X})
=O(X^{c\log 2})
=o\!\left(\frac X{\log X}\right).
\]

The prime number theorem therefore shows that, among primes in every dyadic
interval, a proportion \(1-o(1)\) has no nonempty zero inverse subset with
multipliers as large as \(c\log p\). This improves the universal constant
\(1\) in (LCF) to every fixed \(c<1/\log 2\) on almost all primes, but it is
an average statement about individual primes and gives no lower-bound sieve
for two adjacent prime-cofactor products.

One adjacent pair can cover a logarithmically larger range of prospective
endpoints. More precisely, fix \(\eta>0\), and suppose

\[
pr+1=qt
\tag{AP}
\]

for primes \(p,q\) and positive integers \(r,t\). For all sufficiently large
\(p,q\), every endpoint \(M\geq qt\) satisfying

\[
\left\lfloor\frac Mp\right\rfloor\leq(1-\eta)\log p,
\qquad
\left\lfloor\frac Mq\right\rfloor\leq(1-\eta)\log q
\tag{AC}
\]

makes the consecutive integers \(pr,qt\) both \(M\)-forbidden, by (LCF).
Thus (AP) excludes every such \(M\), not only endpoints of size comparable
with \(pr\). This amplification makes finite certificates much more efficient.
It does not remove the asymptotic obstacle: producing enough solutions of
(AP) with both cofactors in the logarithmic range is still a two-prime
sieve problem of the same parity-sensitive type.

### Forbidden integers need an almost-linear prime-power divisor

The preceding reduction has a strong asymptotic restriction. For every
\(\theta>0\), there is an \(M_0(\theta)\) such that, whenever
\(M\geq M_0(\theta)\), every \(M\)-forbidden integer has a prime-power divisor

\[
Q>M^{1-\theta}.
\tag{AL}
\]

To prove this, use Theorem 5 of Conlon, Fox, He, Mubayi, Pham, Suk, and
Verstraëte,
[A question of Erdős and Graham on Egyptian fractions](https://homepages.math.uic.edu/~mubayi/papers/Egypt.pdf).
That theorem says the following. Given fixed \(\delta,\varepsilon>0\), for
every sufficiently large prime power \(q\), if

\[
I\subseteq[q^\varepsilon,2q^\varepsilon],\qquad
\gcd(x,q)=1\quad(x\in I),\qquad |I|\geq\delta q^\varepsilon,
\]

then every residue modulo \(q\) is a sum of inverses of a subset of \(I\).

Fix \(0<\varepsilon<1\), and suppose \(n\) is \(M\)-forbidden, witnessed by
\(p,E\), with \(Q=p^E\), \(s=\lfloor M/Q\rfloor\), and \(r=n/Q\) as above.
If \(p\) is sufficiently large and \(s\geq2p^\varepsilon\), let

\[
I=\bigl([p^\varepsilon,2p^\varepsilon]\cap\mathbb Z\bigr)\setminus\{r\}.
\]

For all sufficiently large \(p\), every element of \(I\) is smaller than
\(p\), and \(|I|\geq p^\varepsilon/2\). The quoted theorem, with
\(q=p\) and \(\delta=1/2\), supplies a subset \(B\subseteq I\) such that

\[
\sum_{t\in B}t^{-1}\equiv-r^{-1}\pmod p.
\]

Moreover \(I\subseteq\{1,\ldots,s\}\) and \(r\notin I\), so
\(B\cup\{r\}\) contradicts the defining condition (F). Hence, for all large
witness primes,

\[
s<2p^\varepsilon,
\qquad
\frac{M}{Q}<s+1<3p^\varepsilon,
\]

Since \(p\leq Q\), it follows that

\[
Q>\left(\frac M3\right)^{1/(1+\varepsilon)}.
\tag{4}
\]

There are only finitely many remaining witness primes, say \(p\leq P_0\).
For those, \(pQ=p^{E+1}>M\), so \(Q>M/P_0\). Given \(\theta>0\), choose
\(\varepsilon\) so that \(1/(1+\varepsilon)>1-\theta\). For sufficiently
large \(M\), both (4) and \(Q>M/P_0\) imply (AL), proving the claim.

The qualitative exponent \(1-o(1)\) can be made explicit. There is an
absolute constant \(C>0\) such that every sufficiently large
\(M\)-forbidden integer has a prime-power divisor \(Q\) satisfying

\[
Q>
M\exp\!\left(
-C(\log M)^{2/3}(\log\log M)^{1/3}
\right).
\tag{QAL}
\]

The required quantitative modular statement follows by retaining the
parameters in Glibichuk's proof of
[Combinational properties of sets of residues modulo a prime and the
Erdős--Graham problem](https://doi.org/10.4213/mzm2708). Namely, for an
absolute \(C_1>0\), every residue \(a\bmod p\) is, for every sufficiently
large prime \(p\), of the form

\[
a\equiv\sum_{i=1}^{N}x_i^{-1}\pmod p
\]

with pairwise distinct positive integers \(x_i\) bounded by

\[
Z(p)=\exp\!\left(
C_1(\log p)^{2/3}(\log\log p)^{1/3}
\right).
\tag{MI}
\]

Here is the parameter calculation, including the distinctness issue. Put
\(L=\log p\),

\[
K=\left\lfloor\left(\frac{L}{\log L}\right)^{1/3}\right\rfloor,
\qquad
X=\left(\frac{p-1}{2K}\right)^{1/(2K-1)}.
\]

In Glibichuk's construction, \(B_K\) is the set of sums of the inverses of
\(K\) distinct primes in \([K+1,X]\). These displayed sums are distinct and
\(B_K\) is antisymmetric modulo \(p\). Indeed, after clearing the at most
\(2K\) prime denominators in a putative equality or opposite pair, the
absolute value of the numerator is at most
\(2KX^{2K-1}\leq p-1\). A congruence modulo \(p\) is therefore an equality
over the rationals; reduction modulo a prime in the symmetric difference
shows that two equal sums used the same primes, while two positive sums cannot
be opposites.

Let \(m=\pi(X)-\pi(K+1)\). Since \(m\gg X/\log X\) and \(m\gg K\), the
standard lower bound for \(\pi(x)\) gives

\[
\begin{aligned}
\log |B_K|
&=\log\binom mK\\
&\geq
K\log\!\left(\frac{cX}{\log X}\right)-\log K!\\
&=
\frac L2+\frac{L}{4K-2}-O(K\log L)
>\frac L2
\end{aligned}
\]

for all sufficiently large \(p\), because \(K^2\log L=o(L)\). Hence
\(|B_K|>\sqrt p\). Glibichuk's additive-combinatorial corollary then gives
\(8(B_KB_K)=\mathbb F_p\), where
\(B_KB_K=\{bb':b,b'\in B_K\}\) and \(8A\) denotes an eightfold sumset.
Expanding the eight products represents every residue as a sum of

\[
N=8K^2
\]

reciprocals whose denominators are at most \(X^2\), although repetitions may
still occur.

For completeness, repetitions can be removed with the exact splitting used
in the same proof. Let \(D=(2N)!\), apply the preceding representation to
\(aD\bmod p\), and initially replace every denominator \(z\) by \(Dz\).
If a denominator \(d=Dz\) occurs twice, then for any
\(1\leq j\leq N-1\),

\[
\frac2d
=
\frac1{Nd/j}+\frac1{Nd/(2N-j)}.
\tag{S}
\]

All denominators in (S) are integers. As \(j\) varies, the \(2N-2\)
candidate denominators are distinct; after removing the duplicated pair,
there are only \(N-2\) other current denominators, and each of those can
spoil at most one of the \(N-1\) candidate pairs. Some \(j\) therefore
produces two new denominators. Repeating removes every repetition without
changing the residue or the number of terms, and all final denominators are
at most \(NDX^2\). Finally,

\[
\log(NDX^2)
=O(K^2\log K)+O(L/K)
=O\!\left(L^{2/3}(\log L)^{1/3}\right),
\]

which proves (MI); this bound is \(o(\log p)\), so none of the constructed
denominators is divisible by \(p\).

Return to an \(M\)-forbidden witness \(p,E,Q,s,r\). Let \(\ell\) be the least
prime not dividing \(r\). Chebyshev's estimate for
\(\sum_{q\leq y,\ q\text{ prime}}\log q\) gives
\(\ell\ll\log(r+2)\), and in particular \(\ell<p\) for large \(p\), since
\(r<p\). Apply (MI) to the residue \(-\ell/r\bmod p\). Multiplying
all its distinct denominators by \(\ell\) gives a set, none of whose elements is
\(r\), whose inverse sum is \(-r^{-1}\bmod p\). Since \(s<p\), for all
large \(p\) the implication

\[
s\geq Z(p)^2
\quad\Longrightarrow\quad
\ell Z(p)\leq s
\]

holds. It would produce the subset forbidden by (F). Thus
\(s<Z(p)^2\). Bounded witness primes satisfy the same final estimate after
enlarging the absolute constant, and \(p\leq Q\leq M\); consequently
\(M/Q<s+1\) gives (QAL).

Thus an asymptotic forbidden pair would have to consist of consecutive
integers each divisible by a prime power larger than \(M^{1-\theta}\), for
every fixed \(\theta>0\) once \(M\) is large enough. Equivalently, their
cofactors are at most \(M^\theta\). This explains a genuine limitation of the
forbidden-pair route: a theorem giving only a fixed exponent
\(Q>M^c\), with \(c<1\), cannot by itself establish the required pair at all
large scales. What remains is an adjacent almost-linear-prime-power problem,
not merely a large-prime-factor problem.

There is a further quantitative consequence. If \(F(M)\) denotes the number
of \(M\)-forbidden integers in \([1,M]\), then

\[
F(M)
\ll
M\left(\frac{\log\log M}{\log M}\right)^{1/3}.
\tag{5}
\]

Indeed, put

\[
G=(\log M)^{2/3}(\log\log M)^{1/3},
\qquad
Y=M\exp(-CG),
\]

with \(C\) enlarged if necessary from (QAL). Once \(M\) is sufficiently
large, every integer counted by \(F(M)\) is divisible by a prime power
\(Q>Y\). The union bound gives

\[
\frac{F(M)}M
\leq
\sum_{\substack{Y<p^e\leq M\\p\text{ prime},\ e\geq1}}\frac1{p^e}.
\]

For \(e=1\), partial summation and the standard Chebyshev bound
\(\pi(x)\ll x/\log x\) give

\[
\sum_{Y<p\leq M}\frac1p
\leq
\frac{\pi(M)}M+\int_Y^M\frac{\pi(t)}{t^2}\,dt
\ll
\frac1{\log M}+\log\frac{\log M}{\log Y}
\ll
\frac{G}{\log M}.
\]

Here \(\log Y=\log M-CG\), and \(CG=o(\log M)\). The contribution of proper
prime powers is

\[
\sum_{\substack{p^e>Y\\e\geq2}}\frac1{p^e}
\ll
Y^{-1/2}\log M,
\]

by summing the convergent tails separately for each exponent; this is smaller
than \(G/\log M\). Since
\(G/\log M=(\log\log M/\log M)^{1/3}\), (5) follows. Thus forbidden integers
are globally sparse with an explicit rate. The conjecture nevertheless needs
a local statement--one adjacent forbidden pair in every sufficiently large
multiplicative window--which does not follow from (5).

## The good-prime obstruction

Call a prime \(p\) *good* when at least one of

\[
\frac{p-1}{2},\qquad\frac{p+1}{2}
\]

is also prime. Suppose a counterexample has first denominator \(a=n_1\) and
last denominator \(M=n_k\), with \(a\geq13\). If a good prime \(p\) satisfies

\[
p+1\leq M\leq2p-3,
\tag{1}
\]

then a contradiction follows.

First, \(M\geq2a\). Otherwise all selected denominators lie among the \(a\)
integers \(a,\ldots,2a-1\), whose reciprocal sum is strictly smaller than
\(a(1/a)=1\). Thus \(a\leq M/2\). Condition (1) places both \(p-1\) and
\(p+1\) strictly between the endpoints \(a\) and \(M\).

The denominator \(p\) cannot be selected, because \(M<2p\) would make it the
unique selected multiple of \(p\), contrary to the prime-power obstruction.
Since two consecutive integers cannot both be absent from a sequence whose
gaps are at most 2, both \(p-1\) and \(p+1\) must therefore be selected.

Let \(q\) be a prime equal to one of the two half-neighbours of \(p\). One of
the selected integers \(p-1,p+1\) is \(2q\). Moreover, (1) implies
\(4q>M\), so the only possible selected multiples of \(q\) are
\(q,2q,3q\). If \(T\subseteq\{1,2,3\}\) is the set of their multipliers,
then \(2\in T\). Clearing denominators and reducing modulo \(q\) requires

\[
\sum_{t\in T}t^{-1}\equiv0\pmod q.
\]

The four possible rational sums have numerators \(3,9,5,11\) over the common
denominator 6. None vanishes modulo a prime \(q>11\). The chain below starts
with the exceptional values \(q=7,11\): the four numerators are already
nonzero modulo 7, while \(q=11<a\) excludes the multiplier 1 and leaves only
the numerators 3 and 5. This proves the obstruction in every case used by the
certificate.

## Controlling the last denominator

The gap condition gives \(n_i\leq a+2(i-1)\). Therefore

\[
1=\sum_{i=1}^k\frac1{n_i}
\geq\sum_{i=0}^{k-1}\frac1{a+2i}
>\frac12\int_a^{a+2k}\frac{dx}{x}.
\]

It follows that \(a+2k<e^2a\), and hence

\[
M+2\leq a+2k<e^2a.
\tag{2}
\]

For completeness, the bounded search also handles the small endpoint needed
here. If \(a\leq12\) and \(k\geq36\), then the first 36 terms alone have sum
at least

\[
\sum_{i=0}^{35}\frac1{12+2i}
=\frac{40219449830612693}{39829125407198400}>1.
\]

The exact search through \(k=100\) rules out all remaining cases, so every
counterexample would indeed have \(a\geq13\).

## Verified finite chain and consequence

For a good prime \(p\), the interval of last denominators excluded by (1) is

\[
I_p=[p+1,2p-3]\cap\mathbb Z.
\]

The certificate contains 66 good primes, begins at 13, ends at

\[
P=147573952589666836319,
\]

and verifies \(p_{j+1}\leq2p_j-3\) for every consecutive pair. Consequently
their intervals cover every integer

\[
14\leq M\leq2P-3=295147905179333672635.
\]

The verifier checks every prime below \(2^{64}\) with the deterministic
seven-base Miller--Rabin test. The entries above \(2^{64}\), and the prime
half-neighbours needed for them, are proved recursively by explicit
Pocklington certificates. It also bounds the exponential series with exact
rational arithmetic. Thirty terms give the certified implication

\[
a\leq39943925344138028689
\quad\Longrightarrow\quad
M\leq2P-3.
\]

This contradicts the interval coverage, so a counterexample must have

\[
a>39943925344138028689.
\tag{3}
\]

Finally, set \(B=39943925344138028689\). From (3), integrality and strict
increase give \(n_i\geq B+i\). Hence

\[
1\leq\sum_{i=1}^k\frac1{B+i}
<\int_B^{B+k}\frac{dx}{x}
=\log\left(1+\frac{k}{B}\right).
\]

Using the exact lower bound for \(e\) from the same 30-term series proves

\[
k\geq68634921076157089631.
\]

The good-prime strategy and finite chains were developed in the
[public discussion of Erdős problem 287](https://www.erdosproblems.com/forum/thread/287).
The repository verifier independently checks the chain and the stated numeric
consequences.

## Why this is not a complete proof

Extending a finite chain never covers arbitrarily large \(M\). A complete
proof by this route would need to show that a suitable good prime occurs in
every sufficiently large interval of the required dyadic form. That is a
difficult unresolved prime-distribution statement closely related to finding
Sophie Germain or safe primes in all such intervals. The same obstruction is
noted in the [public problem record](https://www.erdosproblems.com/287).

The asymptotic restrictions above do not bypass that gap. In particular,
(AG) forces \(\gg_\varepsilon M^{23/24-\varepsilon}\) unit gaps, but this is
still \(o(M)\) among \(\Theta(M)\) possible positions. If the unit gaps have positive
linear density, (PR), (RT),
and (BT) push the forced prime-factor scale higher and reach correspondingly
larger pointwise layers. Moreover, (RL) places linearly many selected terms in
layers of logarithmically growing cardinality, and (RD) strengthens this to a
fixed positive multiplier density, in either regime. The compression identity
(CP) removes the large prime from each complete active layer, but loses the
ordering and gap information when it replaces that layer by one rational
number. The resulting phase, density, and mass bounds therefore remain
compatible with total reciprocal sum 1. The forbidden-pair
approach still needs a local correlation theorem for two consecutive
almost-prime-power products, or a different global argument that retains the
gap condition while using the complete family of \(p\)-adic congruences.
Neither has been proved in this note.

## Reproducible result

The program enumerates every remaining branch and uses Python `Fraction`
values, so no floating-point comparison is involved. The repository run found
no counterexample for any \(2\leq k\leq100\). At \(k=100\) it visited 38,036
search nodes and returned `witness: null`.

From the repository root, the endpoint run is:

```console
python scripts/search_unit_fraction_gaps.py --length 100
```

To repeat every length through 100 in one invocation, use:

```console
python scripts/search_unit_fraction_gaps.py --max-length 100
```

To verify the good-prime chain, its Pocklington certificates, interval
coverage, and both final bounds, use:

```console
python scripts/verify_unit_fraction_good_prime_chain.py
```

These computations establish the stated finite exclusions only. A complete
solution still needs an argument covering arbitrarily large denominators.
