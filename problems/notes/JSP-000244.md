# JSP-000244: bounded exact verification

[Problem record](../catalog-0201-0300.md#JSP-000244) · [Search program](../../scripts/search_unit_fraction_gaps.py)

This note proves that every fixed denominator count reduces to a finite exact
search and records the repository's verification through 25 denominators. It
does **not** prove the unrestricted conjecture.

## Statement

The conjecture asks whether every representation

\[
1=\frac1{n_1}+\cdots+\frac1{n_k},\qquad 1<n_1<\cdots<n_k,
\]

has some consecutive gap at least 3.

## Finite-reduction lemma

Fix an integer \(k\geq2\). If a counterexample of length \(k\) exists, it is
among the finitely many sequences obtained by choosing

\[
n_1\in\{2,\ldots,k-1\}
\quad\text{and}\quad
(n_{i+1}-n_i)_{i=1}^{k-1}\in\{1,2\}^{k-1}.
\]

**Proof.** In a counterexample every gap is a positive integer smaller than 3,
so every gap is 1 or 2. It remains to bound the first denominator. If
\(n_1\geq k\), then \(1/n_i\leq1/n_1\) for every \(i\), with a strict
inequality for every \(i>1\). Therefore

\[
\sum_{i=1}^k\frac1{n_i}<\frac{k}{n_1}\leq1,
\]

contradicting the required equality. Hence \(2\leq n_1<k\), and the stated
finite enumeration is exhaustive. \(\square\)

## Sound pruning lemma

Suppose a partial candidate currently ends at denominator \(c\), has reciprocal
sum \(S\), and still needs \(r\) denominators. For the \(j\)th future
denominator \(m_j\), the gap restriction gives

\[
c+j\leq m_j\leq c+2j.
\]

Consequently every completion has its remaining sum in the exact interval

\[
\sum_{j=1}^r\frac1{c+2j}
\ \leq\
\sum_{j=1}^r\frac1{m_j}
\ \leq\
\sum_{j=1}^r\frac1{c+j}.
\]

It is therefore sound to discard a branch when the upper endpoint added to
\(S\) is below 1, or when the lower endpoint added to \(S\) is above 1. Equality
is not pruned. These are exactly the two pruning rules used by the program.

## Reproducible result

The program enumerates every remaining branch and uses Python `Fraction`
values, so no floating-point comparison is involved. The repository run found
no counterexample for any \(2\leq k\leq25\). At \(k=25\) it visited 1,333,871
search nodes and returned `witness: null`.

From the repository root, the endpoint run is:

```console
python scripts/search_unit_fraction_gaps.py --length 25
```

To repeat every length through 25 in one invocation, use:

```console
python scripts/search_unit_fraction_gaps.py --max-length 25
```

This establishes the conjecture for the stated finite range only. A complete
solution still needs an argument covering every \(k\).
